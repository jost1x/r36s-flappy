# R36S y despliegue

## Compilación ARM64

La build para R36S usa Docker y Debian Buster para mantener compatibilidad con la versión de glibc de ArkOS. Raylib se compila con el backend DRM/KMS y renderizado por software: no depende de un servidor X11 ni de que el driver 3D esté disponible.

```sh
make r36s
```

El resultado queda en `bin/r36s-arm64/r36s-flappy`.

## Despliegue

```sh
export R36S_IP=192.168.1.100
export R36S_USER=ark  # opcional
make deploy
```

El script instala el binario en `/opt/r36s-app/bin` y añade un lanzador `r36s-flappy.sh` al directorio de Ports si lo encuentra.

## Requisitos en R36S

- ArkOS con acceso SSH habilitido
- Usuario `ark` (o el que configures con `R36S_USER`)
- Docker con buildx en la máquina de desarrollo
