# R36S y despliegue

## Compilación ARM64

La build para R36S utiliza Docker y Debian Buster para mantener compatibilidad con la versión de glibc de ArkOS.

```sh
make r36s
```

El comando ejecuta `build-r36s.sh` y deja el binario en:

```text
bin/r36s-arm64/r36s-hello
```

El Dockerfile descarga LVGL 9.2.2 y compila los iconos con `LV_CONF_INCLUDE_SIMPLE` y `LV_LVGL_H_INCLUDE_SIMPLE`.

## Despliegue

```sh
export R36S_IP=192.168.1.100
export R36S_USER=ark          # opcional; valor predeterminado
export R36S_PORT=22           # opcional; valor predeterminado
make deploy
```

Opcionalmente, configura `R36S_SSH_KEY` con la ruta de la clave privada. El script instala el binario en `/opt/r36s-app/bin` y, si detecta un directorio de Ports, añade un lanzador para EmulationStation.
