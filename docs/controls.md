# Controles

| Acción | Teclado | R36S |
| --- | --- | --- |
| Volar / empezar / reintentar | Clic izquierdo, Espacio, Enter, ↑ o W | A, B, Start, L1 o R1 |
| Pausar / continuar | P | Start |
| Salir | Escape | Select + Start |
| Silenciar | M | — |

El juego acepta múltiples botones porque la asignación física puede variar entre imágenes de ArkOS y los mapeos de mando de raylib.

## Dificultad

La dificultad aumenta automáticamente cada 5 puntos:
- La velocidad de las tuberías incrementa ~10%
- El gap entre tuberías se reduce gradualmente (mínimo 120px)

El nivel se reinicia al comenzar una nueva partida.
