# Controles

| Acción | Teclado | R36S |
| --- | --- | --- |
| Volar | Clic izquierdo, Espacio, Enter, ↑ o W | A, B, L1 o R1 |
| Navegar menús | Flechas o W/S | Cruceta arriba/abajo |
| Ajustar volumen | Flechas izquierda/derecha o A/D | Cruceta izquierda/derecha |
| Confirmar menú | Enter o Espacio | A |
| Volver en menú | Escape o Retroceso | B |
| Abrir opciones | O | Select |
| Pausar / continuar | P | Start |
| Salir | Escape | Select + Start |
| Silenciar | M | — |

El juego acepta botones alternativos para volar porque la asignación física puede variar entre imágenes de ArkOS y los mapeos de mando de raylib. Los menús, en cambio, están diseñados para usarse completamente con la cruceta, A y B; no requieren pantalla táctil ni ratón.

## Dificultad

La dificultad aumenta automáticamente cada 5 puntos:
- La velocidad de las tuberías incrementa ~10%
- El gap entre tuberías se reduce gradualmente (mínimo 120px)

El nivel se reinicia al comenzar una nueva partida.
